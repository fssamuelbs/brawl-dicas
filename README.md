# 🎮 Brawl Dicas

> Sua rede do competitivo de Brawl Stars! Encontre o meta atualizado, criadores de conteúdo, ferramentas de estatísticas e os principais campeonatos em um só lugar.

Plataforma web desenvolvida como **Projeto Integrador** para a disciplina de **Programação Web** na **Universidade do Estado do Pará (UEPA)**.

---

## 🚀 Sobre o Projeto
O **Brawl Dicas** nasceu da necessidade de centralizar informações do cenário competitivo de Brawl Stars, que costumam ficar dispersas em várias plataformas. O site oferece uma interface moderna, responsiva e de fácil navegação para os jogadores acompanharem o meta, estatísticas de progresso e grandes campeonatos.

---

## 🛠️ Tecnologias e Ferramentas

O projeto foi desenvolvido utilizando as seguintes tecnologias e ferramentas:

* **HTML5:** Estruturação semântica e organização das páginas.
* **CSS3:** Estilização visual personalizada, tipografia e design responsivo.
* **JavaScript:** Dinamismo e interatividade no front-end.
* **Canva:** Prototipagem e pré-design da interface.
* **VS Code / CodeSandbox:** Ambientes de desenvolvimento local e online.
* **Git e GitHub:** Controle de versão e versionamento de código.
* **GitHub Pages:** Hospedagem e deploy contínuo da aplicação.
* **Postimages:** Hospedagem externa e otimização de assets de imagem.
